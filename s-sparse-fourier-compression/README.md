## S-sparse Fourier Compression

This folder is not directly relevant to the other gnuradio scripts. In here are scripts. They have been placed in this repo for their miscellaneous character.

These scripts are experiments in python with different types of compression, looking at the document on the
drive on image compression will explain where each quantisation table came from. As Armann has now 
implemented JPEG XL into the camera image format this code will no longer be updated or needed. It has
been left here for archival purposes.
